What the live audit found

INSTALL MERGE

Claude drops one managed validator

Two canonical write groups use the same matcher. The installer replaces the first group with the second. The live configuration is missing the shared validator registration.

DUPLICATE EXECUTION

Eight effective routes repeat

Live Claude and Codex configurations keep legacy direct checks beside dispatcher children. A single action can run the same policy twice.

MISSING TARGET

Codex points to two absent scripts

The diagnostic stop wrapper and task list loop starter are registered but missing from the installed hook tree.

FALSE POSITIVE

Safe PowerShell inspection was denied

The Bash shell substitution rule interpreted a PowerShell backtick as command substitution during this audit.

ORDERING RISK

Pull request author state can remain switched

The author gate changes the global GitHub account before a later body gate can deny the same command. The restore event then does not run.

GIT RISK

Push checks do not prove every pushed object

The pre-push path checks the first update and the checkout head. It has no deadline around the shared gate process.

HIDDEN SIDE EFFECT

Post-commit can create another commit

A submodule commit can trigger a parent repository commit. Move that action to an explicit sync command.

RUNTIME EVIDENCE

The block log reached 117 MB

The snapshot held 182,713 valid block decisions and 11 malformed records. One recorded pre-commit gate timed out after 240 seconds. These are events, not unique user interruptions.
