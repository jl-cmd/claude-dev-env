# Obsidian vault context

An Obsidian vault holds session reports (`sessions/`), decisions (`decisions/`), and research (`Research/`) across projects, reached through the obsidian MCP tools.

Before substantive project work, use the obsidian MCP tools to search the vault for prior sessions and decisions on the current project. Search by `project` frontmatter first, then by keyword. Search again when touching a component with known history, or when a task might repeat or reverse a prior decision.
